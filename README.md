# DR Lab — второй экран трейдера DR/IDR

DR Lab — локальный инструмент одного трейдера (оператора), который торгует по методу DR/IDR (автор TheMas7er, академия
M7DR). Рядом с TradingView он показывает текущую сессию NQ, ES или YM с уровнями DR / IDR / STD и то, как вели себя
похожие сессии 2006–2025. Это описание истории, а не сигнал и не сделка. Репозиторий — смысл, код, спецификации и
проверки инструмента, общее место работы для агентов.

*English: a local second screen for a DR/IDR futures trader. Today's session with the author's DR/IDR levels and, from
similar sessions of 2006–2025, the author's Time & Price on the sessions whose DR held. Every number is checked against
a machine-readable semantic contract (DR-LAB-SC-1.1). The semantic layer is in Russian; agents start at
[`AGENTS.md`](AGENTS.md).*

- **Сетка STD** стоит с конца часа бокса по цвету бокса; подтверждение только уточняет сторону. То же правило — в
  скрипте TradingView «90».
- **Экран 24** «Границы хода» сохранён как работает, на `/24/` (ярлык «DR Lab 24»).
- **Смысловой контракт DR-LAB-SC-1.1** и его машинная форма [`contract/`](contract/README.md): каждое число экрана —
  зарегистрированная величина с явным утверждением; сервер пересчитывает её перед выдачей.

## Жёсткие правила

Рыночные данные (лента, свечи по дням, результаты по отдельным датам) сюда никогда не попадают — репозиторий публичный,
здесь только агрегаты. 2026 год в базе истории скрыт. Без Volume. Сервер только локальный. Ордеров и торговых решений
нет: ни одно число инструмента не является прогнозом или сигналом. Полный список — в [`AGENTS.md`](AGENTS.md).
