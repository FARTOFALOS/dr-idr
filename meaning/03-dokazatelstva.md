# 03 · Что установлено на ленте 2006–2025

Лента — минутные NQ, ES, YM с 2006 по 2025 год (2026 скрыт). Числа ниже — агрегаты; каждое можно пересчитать скриптом из
[`../studies/`](../studies/). Если не сказано иное, числа даны через дробь в порядке NQ / ES / YM, «п.» — процентные
пункты. Статусы — в [README](README.md#метки-статуса).

## 1. Правило DR и описательные утверждения автора

**[проверено]** После подтверждения на RDR противоположный край DR не пробивается закрытием M5 до конца сессии в
**83 / 80 / 81 %** сессий, на ODR — около 77–80 %, на ADR — около 72–76 %. «Около 80 %» у автора для RDR и ODR верно,
«88 %» (2022, без новостных дней) не подтверждено. Цвет коробки совпадает с направлением подтверждения в **71 %**
подтверждённых RDR; после подтверждения цена возвращается к краю DR в 88–91 % сессий; +0,5 STD достигается примерно в
80 %. Источник: `studies/m7_claims.py` (25.09), [`../docs/STRATEGY.md`](../docs/STRATEGY.md) §14.

**[проверено]** Публичная формулировка автора в индикаторе — «DR low будет минимумом сессии с вероятностью 80 %», то есть
про тень, а не про закрытие. В таком прочтении на RDR выходит **75 / 70 / 73 %**. Если ограничиться тенями после
подтверждения, выходит 80 / 76 / 78 %; по закрытию — 83 / 79 / 81 %. Независимые открытые тесты дают близкое к теневому
прочтению: 71,7 % (TFO, ES, 237 сессий) и около 76 % (SPY 2004–2019). Источник:
`studies/audit_2026_09_29/geometry_nulls.log` (поля lit и wick).

## 2. Эти частоты — геометрия, а не «уважение уровней»

Вопрос: нужно ли что-то сверх размера коробки и волатильности дня, чтобы получить эти частоты? Проверка: коробку
оставляем настоящей, а путь цены после неё заменяем двумя способами:
- **P60** — свечи того же дня перемешаны внутри каждого часа; сохраняются форма свечей, цена на границах часов и
  профиль волатильности;
- **NBR** — путь соседнего дня (±10 торговых дней), который об этой коробке ничего не знает.

| Утверждение | Лента | P60 | NBR | Статус |
|---|---|---|---|---|
| DR удержится, RDR | 82,6 / 79,1 / 80,7 % | 82,7 / 79,7 / 81,2 | 81,1 / 77,9 / 79,5 | **[проверено]** геометрия: на ленте не выше, чем без связи с коробкой |
| DR удержится, ODR | 77,5 / 79,5 / 77,7 % | 75,9 / 77,7 / 76,4 | 75,7 / 76,7 / 75,8 | **[частично]** остаток +1…+3 п., не объяснён |
| DR удержится, ADR | 73,6 / 75,7 / 73,0 % | 71,8 / 72,8 / 71,9 | 70,8 / 73,1 / 70,6 | **[частично]** остаток +1…+3 п. |
| Цвет коробки → направление, RDR | 71,4 / 70,8 / 70,3 % | 72,0 / 70,7 / 70,4 | 70,8 / 69,8 / 70,2 | **[проверено]** геометрия |
| Возврат к краю DR, RDR | 88,8 / 91,1 / 90,6 % | 90,8 / 92,3 / 91,1 | 90,0 / 91,4 / 90,6 | **[проверено]** геометрия (на ленте даже чуть реже) |
| +0,5 достигнута, RDR | 77,5 / 81,1 / 79,1 % | 77,0 / 81,6 / 78,9 | 77,1 / 81,0 / 78,7 | **[проверено]** геометрия |

Как это работает для цвета: зелёная коробка закрывается в среднем на 0,78–0,80 высоты DR, красная — на 0,25–0,27.
Первое подтверждение уходит к ближнему краю DR в 73–74 % случаев, то есть даже чуть чаще, чем по цвету. Источник:
`studies/audit_2026_09_29/geometry_nulls.{py,log,json}`.

**[проверено]** **Модели дня.** Разница в доле лонг-подтверждений RDR между днями «жива только модель роста» и «жива
только модель снижения» на ленте +17,6 / +14,4 / +14,4 п., на пути соседнего дня +19,8 / +14,4 / +17,4 п. Внутри одного
цвета коробки на ленте остаётся от −2,0 до +3,7 п. Модели — хорошее описание дня, но новой информации о направлении сверх
цвета коробки они не несут. Источник: `studies/audit_2026_09_29/models_vs_colour.{py,log}`; определение моделей — как у
рабочего экрана (совпадает с проверкой C7a в 98 % дней).

## 3. Что даёт сам час коробки (якорь 03:00, 09:30, 19:30)

Та же коробка на часовых окнах, начинающихся в любое время суток, с одинаковым горизонтом 240 минут.

- **[проверено]** **Против фактической волатильности после окна.** Частота «DR удержится» почти целиком объясняется
  отношением ширины коробки к диапазону следующих часов: R² 0,99 примерно по 210 стартам на инструмент. Остатки:
  - 09:30 — −2,1 / −1,7 / −2,4 п.: самая высокая частота дня, но ниже кривой;
  - 03:00 и 19:30 — лежат на кривой.

  Это объяснение задним числом. Источник: `studies/audit_2026_09_29/anchor_placebo{.py,_fit.py,.log,_fit.log}`.
- **[проверено]** **Против заранее известного.** Ожидаемый диапазон берём как медиану того же окна за 20 прошлых дней.
  При одинаковом ожидаемом отношении окна 03:00 и 09:30 удерживаются на **1,9–2,7 п.** чаще соседних окон в пределах ±45
  минут. Интервалы по дням не включают ноль (логистическая модель и 20 корзин дают одно и то же). У 19:30 разница
  +0,6…+1,2, для YM интервал включает ноль. Источник: `studies/audit_2026_09_29/anchor_exante{,_robust}.{py,log}`.
- **[открыто]** Механизм этих двух пунктов не установлен. Перестановка свечей внутри часа частоту на RDR не меняет, значит,
  дело не в реакции пути на уровни. Вероятнее всего, эффект идёт через саму волатильность: коробка открытия шире
  относительно дальнейшего движения, чем подсказывает история этого часа. Это вывод, не проверка.

## 4. Механические входы автора

**[проверено]** На NQ/ES/YM retirement setup и процедура time & price **положительного преимущества не показали**: средние
результаты после издержек отрицательны. Для retirement на RDR интервалы ниже нуля (−0,10 / −0,33 / −0,15 R). Для time &
price на NQ RDR интервалы включают ноль: −0,025 R [−0,106; 0,056] и −0,016 R [−0,073; 0,042]. Правильная формулировка —
«положительное преимущество не установлено; средняя оценка отрицательна», а не «убыточно».

Главная ловушка чисел автора: статистика QuantX строится только по сессиям, где DR удержался. Это условие на будущее; на
ленте параметры по таким сессиям дают 67–81 % стопов. Источник: `studies/m7_claims.py`,
[`../docs/STRATEGY.md`](../docs/STRATEGY.md) §14–15.

## 6. Как легко прочитать не то событие

- **[проверено, для прежнего объекта — окончательных экстремумов дизайна 21]** **Место, ядро и самое плотное место.** Ядро созвездия содержит в медиане 0,32–0,38 сессий своего места
  (около 0,30 у мест от 20 %); у 64–75 % мест — меньше половины. Самое плотное место вместе с его временем — около 0,06.
  Процент, нарисованный на ядре, относится к области примерно втрое большей, чем видно. Источник:
  `studies/audit_2026_09_29/place_core.{py,log}`.
- **[проверено]** **Веер.** Целиком внутри веера 20–80 % проходит 12 % (RDR) и 13 % (ODR) путей похожих сессий. У
  сегодняшнего пути так же: около 11–12 %.
- **[частично]** **«Время» мест у конца сессии.** В ранние моменты, когда до конца больше 3–3,5 часа, в последние 30
  минут попадает 28–31 % окончательных экстремумов похожих при 12,7–15,5 % для равномерного времени. У самого дня так же:
  29–33 %. Самое плотное 5-минутное окно попадает в последние полчаса в 75–98 % таких моментов. Для пути без дрейфа закон
  арксинуса даёт 27–36 % в зависимости от часов волатильности: порядок величины совпадает, точного совпадения нет.
  Вывод: «когда» места в экране 21 — это в основном свойство события «экстремум до конца сессии», а не время, когда цена
  туда приходит. Источник: `screen_replay.log`.
- **[проверено]** **«Пусто».** На новых днях сегодняшний откат заканчивается внутри «пустого» интервала в 4,5–5,7 %
  случаев — столько же, сколько в соседних интервалах той же ширины (3,5–6,9 %). Пустота — шум малой выборки. Как место
  для стопа этот интервал ничем не лучше соседних. Источник: `studies/audit_2026_09_29/empty_interval.{py,log}`.

## 7. Что не проверено

- Как оператор на самом деле читает экран: путает ли он полосу и ядро, веер и коридор. Измерен только размер разницы.
- Порядок событий: цель раньше стопа, откат раньше продолжения. Позже проверены два варианта: приход в место
  продолжения раньше тени за противоположным DR (раздел «7а») и допустимый приход в место отката, затем +1,0 раньше
  слома DR (раздел 10). Порядок «цель раньше стопа по цене» для сделки не измерялся.
- Дизайн 22 на рыночных данных: он пока макет. Его правила проверены только тем, что числа, которые он скрывает или
  меняет, проверены выше.
- Новостные дни, другие инструменты автора (CL, 6E, GC, BTC), 2026 год (открывается только решением оператора).
- Дискреционный вход автора по отказу от уровня со стеком подтверждений (S1).

## 7а. Проценты мест после перехода на «куда приходила цена» (29.09, вечер)

Скрипт `studies/audit_2026_09_29/place_arrivals.py`, журнал `place_arrivals.log`: каждый день 2016–2025 каждые 15 минут,
похожие только из прошлых лет, NQ/ES/YM, RDR и ODR, все места впереди цены.

- **[проверено]** При ● (цена сопоставлена ±0,25 IDR) проценты мест сбываются: обещано 49 % — было 45–49 %, обещано
  86 % — было 85–87 %; BSS 19–26 % во всех состояниях.
- **[проверено]** При ◐ (±0,5) навык тот же или выше (BSS 17–30 %), но самые уверенные проценты завышены после
  подтверждения: обещано 87 % — было 70–78 %.
- **[проверено]** При ○ (цена не сопоставлена) после подтверждения и после слома проценты хуже постоянной оценки
  (BSS −16…−44 %): обещано 90 % — было 40–59 %. Прочерки при ○ оправданы. До подтверждения при ○ слабый навык есть
  (BSS 3–11 %).
- **[проверено]** Порядок: «цена пришла в место продолжения раньше, чем тень выбила стоп за противоположным DR» —
  тоже сбывается при ● и ◐ (BSS 12–18 %; в среднем обещано 35–44 %, было 29–42 %), при ○ — нет (−58…−74 %).

## 10. Проверка по линзе 8 (30.09): приход, допустимость, последовательность на одном договоре

Скрипты и журналы — `studies/lens8_2026_09_30/`, договор — `dogovor.md` (версия 1.1), ответ линзе —
