# Смысловой слой DR Lab — вход для агента без кода

Здесь всё, что нужно, чтобы понимать DR Lab, спорить о нём и предлагать изменения **на уровне смысла, не открывая
код**. Код, данные и проверки ведёт агент-исполнитель (его вход — [`../AGENTS.md`](../AGENTS.md)). Решения принимает
оператор — трейдер, для которого сделан инструмент.

## Начать отсюда (11.11.2026)

**[25 · TP-2.0, спецификация для инженера](25-tp-2-0-specifikaciya.md)** — действующая основа основного экрана 23.5,
принята оператором 10.11. Коротко: исход DR — по всей семье; всё остальное — только по true-сессиям (DR удержали):
сначала время отката (пучки, медиана, 70 %, окна W1/W2), потом цена внутри окна (места отката среди сессий окна),
потом продолжение у этих же сессий (часы вершин и места вершин). Каждое янтарное число — доля всей семьи N; пучок или
место существует только при max(4, ⌈0,05·N⌉) сессиях. Как встроено — [docs/DR-LAB-23-5-TP.md](../docs/DR-LAB-23-5-TP.md).

## Метки статуса

| Метка | Значит |
|---|---|
| **[проверено]** | Измерено на ленте 2006–2025 с заранее записанным правилом; есть скрипт и журнал |
| **[частично]** | Измерено, но объяснение или граница применимости не установлены до конца |
| **[вывод]** | Следует из проверенного, но отдельно не измерялось |
| **[гипотеза]** | Предположение, которое можно проверить |
| **[опровергнуто]** | Проверено, не подтвердилось |
| **[решение оператора]** | Сказал оператор; дата и источник в `docs/DECISIONS.md` |
| **[предложение]** | Предложил агент; действует только после решения оператора |
| **[открыто]** | Никто не решил и не проверил |

## Как предложить что-то

Текст линзы попадает в [`lens/`](lens/) (через оператора, Issue или PR), исполнитель отвечает там же, проверяет
утверждения на данных и обновляет эти файлы; решения остаются за оператором. Подробно — [06-protokol.md](06-protokol.md).
