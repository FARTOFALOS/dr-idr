# DR-LAB-CLUSTER-SYNTHESIS-1.0 и его независимый аудит (01.10.2026)

**Происхождение.** Оба документа оператор вставил в чат исполнителя 01.10.2026 после проверки правила `main-cluster-1`
([meaning/11](../../11-glavnyj-klaster.md)), сначала спецификацию, затем линзы. Здесь они сохранены дословно, только
текст, без правок:

- [`DR-LAB-CLUSTER-SYNTHESIS-1.0.md`](DR-LAB-CLUSTER-SYNTHESIS-1.0.md) — кандидат на единый контракт автоматической
  главной области поверх DR-LAB-SEM-1.0 / Design 24. Лестница «распределение → опорная область → устойчивая область →
  структурный кластер», path-null со случайным отражением свечей M5, калибровка отдельной осью. Сводит три линии:
  - первая — `main-cluster-1` этого исполнителя;
  - вторая и третья — работы других агентов, которые этот исполнитель не читал (указание оператора 01.10);
- [`linzy-audita.md`](linzy-audita.md) — 15 вопросов и заключительный вопрос для независимого чтения спецификации. По их
  собственному статусу это не часть алгоритма и не порядок аудита.
- [`peresmotr-avtora.md`](peresmotr-avtora.md) — пересмотр автора синтеза, вставленный оператором во время аудита.
  Автор отказывается от четырёх уровней. Новый центр — «семейство автоматических price×time-зон R/X»; устойчивость,
  перенос вперёд и null становятся свойствами зоны, условный слой выносится отдельно.

**Ответ исполнителя:** [`otvet-auditora.md`](otvet-auditora.md). Расчёты к нему:
[`studies/cluster_synthesis_audit_2026_10_01/`](../../../studies/cluster_synthesis_audit_2026_10_01/README.md).
