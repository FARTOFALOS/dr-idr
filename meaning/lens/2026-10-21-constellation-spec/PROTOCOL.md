# Независимая проверка определения созвездия — протокол 21.10.2026

Записан до нового расчёта кандидата. Это исследовательское предложение Codex по запросу оператора, не изменение SC-1.1 или экрана. Линзы №17/№19 и локальные исследования — источники, не решения оператора и не готовые ответы.

## Проверяемый кандидат

`constellation-neighbourhood-1` (CN-1): точные направленные цены и M5-времена одного именованного исхода; по одной точке на сессию, общий N с некоординатной массой.

- Полуширина соседства цены: 3/20 SD = 0,15 ширины IDR.
- Полуширина соседства по времени открытия M5: 20 минут (четыре шага M5 в каждую сторону).
- Метрика: `max(|du|/(3/20), |dt|/20)`; два отдельных допуска, не физическое равенство цены и времени.
- Опора: `m=max(4, ceil(N/20))`; окрестность закрыта, включает саму точку, считаются разные case_id.
- Ядро: точка с >=m соседями на расстоянии <=1.
- Компоненты связности графа **только ядер**; ребро при расстоянии <=1. Один компонент допустим.
- Точка относится к единственному ближайшему компоненту ядра, если расстояние до него <=1. Равные минимумы разных компонентов — отдельный остаток SHARED_BORDER. Неядерная точка не соединяет компоненты.
- Компонент публикуется как область кандидата, если после этого у него >=m членов. Отброшенные компоненты не перераспределяют свои точки другим компонентам; их область остаётся названным остатком.
- Геометрия области — тот же предикат единственного ближайшего ядра в непрерывных координатах. Число считается по нему, не по bounding box или декоративной плотности.
- Размеры соседства фиксированы до проверки; не подбираются для появления второй зоны YM.

## Сравнения

1. Синтетика: один плотный остров; два острова; одинаковая цена в далёкие часы; широкое редкое поле; плотное плато; редкий/плотный мост; общая граничная точка; разный порядок входа; перенос начала координат; масштабирование тиков; разные case_id на одной координате; повтор case_id; некоординатная масса в N; ровно граничные расстояния.
2. Существующий `zone-map-3` на тех же известных FINAL-R и FINAL-X. Объект не меняется одновременно с кластеризатором.
3. Исторические семьи подтверждения на конец базы: NQ/ES/YM × ADR/ODR/RDR × понедельник–пятница × long/short × окна 0,1,2. 270 фиксированных семей, два исхода; все даты строго раньше 2026-01-01. N<20 — отдельная описательная группа, не скрытое исключение.
4. Чувствительность и удаление случаев: заранее выбранные девять семей вторника, long, окно 0 (каждый инструмент × блок), отдельно R/X. По 20 детерминированных удалений 10% **всех** членов семьи, включая случаи без координаты. Новый N соответствует оставшимся случаям. Жаккар считается на оставшихся общих ID; исчезновение области даёт 0.
5. Масштабы для диагностики, не поиска победителя: цена 0,10/0,15/0,20 при времени 20; время 15/20/25 при цене 0,15. Основная версия остаётся 0,15/20 независимо от результата.
6. YM RDR вторник long окно 0 — отдельный уже виденный регрессионный пример, не выборка валидации.

Выводы: детерминизм, отсутствие сеточной фазы, разбиение массы и точность региона — обязательные свойства. Новые агрегаты служат сравнением геометрии и устойчивости, а не доказательством S/V/H или превосходства в торговле. Не объявлять метод лучшим по одному увеличению массы покрытия; прямо показывать слияние и широкие компоненты. Нет целевого количества созвездий, целевого покрытия 70%, фильтра по null или по будущему успеху.

## Границы

CCPB из линзы №19 не считается принятым новым R и не смешивается с FINAL-R/RPX. Отдельно разбираются его условия, масштаб и смысл отсутствия события. Новое исследование CCPB, прогнозная проверка и новый UI не выполняются этим прогоном.

Рынок и индивидуальные исходы не сохраняются в пакете; только агрегаты. Историческая база 2026 закрыта. Рабочие калькуляторы, шлюз, launcher, формы SC и frozen FOM не меняются. Пишутся только файлы этого предложения.
