## 3. Сверка: отличается ли зона откатов от простого посещения

Вопрос: если в зоне откатов кончался откат у 62 % семьи, то сколько сессий там просто побывало? Если почти все,
то зона говорит в основном «цена здесь торговала», а не «здесь кончаются откаты».

Скрипт — `studies/pb_vs_visits_2026_10_21.py`, печатает только агрегаты. На каждую зону: **L** — доля семьи с
установленным дном отката в клетках зоны (нижняя граница доли кандидата); **посещение** — доля сессий, у которых
закрытая M5 после собственной активации задела клетку зоны в её 15-минутном столбце (та же проверка, что кандидат
делает для сегодняшнего дня); **L / посещение** — какая часть побывавших закончила там откат.

| Сцена | Масштаб | Зона | L | Посещение | L / посещение |
|---|---|---|---|---|---|
| NQ RDR 17.12.2025 11:10, день недели, N = 156 | 1 | 10:30–14:00 | 61,5 % | 90,4 % | 0,68 |
| | 2 | 10:30–13:00 | 50,0 % | 87,8 % | 0,57 |
| | 3 | 10:45–12:30 | 30,1 % | 82,7 % | 0,36 |
| | 6 | 11:00–12:15 | 17,9 % | 78,2 % | 0,23 |
| NQ RDR 17.12.2025 11:10, все дни, N = 709 | 1 | 10:30–14:15 | 64,6 % | 94,5 % | 0,68 |
| | 6 | 10:45–12:45 | 21,9 % | 81,9 % | 0,27 |
| ES ODR 12.11.2025, N = 59 | 1 | 04:30–08:00 | 67,8 % | 94,9 % | 0,71 |
| | 6 | три зоны | 7–14 % | 46–76 % | 0,09–0,26 |
| YM ADR 08.10.2025, N = 73 | 1 | одна зона | 35,6 % | 83,6 % | 0,43 |

Что из этого следует.

- **На масштабе 1 зона откатов почти совпадает с областью, где торговали 90–95 % сессий.** Две трети побывавших
  кончили там хоть какой-то мелкий откат. Это следствие определения: при «вершине выше одной соседней свечи слева и
  справа» почти любая торговля в одном месте даёт мелкие откаты. Доля 62–72 % на экране — правда, но трейдер может
  прочитать её как «здесь особое место откатов», а она близка к «здесь цена была».
- **С ростом масштаба зона уже, а побывавших по-прежнему много (78–82 % в NQ RDR).** Откат там кончает меньшая часть
  побывавших (0,23 на масштабе 6). Это и есть то, что зона откатов добавляет к посещению. Сверка не говорит, лучше
  ли эта зона, чем любое другое место с той же посещаемостью: такой контроль не делался.
- Это описание истории семьи, не прогноз и не проверка выгодности.
