**Поправка оператора к §§5.1, 12, 13.2 (01.10.2026, в чате исполнителя).** Рабочий атом — уже существующая
пятиминутная свеча базы. Если у clock-M5 есть OHLC, это наблюдение, днём и ночью одинаково: ADR, ODR и RDR считаются
одинаково. Устанавливать, из скольких минутных записей собрана свеча, не нужно. Дыркой считается только полностью
отсутствующая M5 на горизонте события, если без неё событие нельзя определить однозначно. Отдельную систему
сертификации минутной ленты не строить.
