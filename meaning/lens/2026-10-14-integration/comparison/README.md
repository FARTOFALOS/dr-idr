# Принятый экран и кандидат на одинаковой реальной истории

[Открыть галерею A/B](index.html) · [машинный протокол](report.json) · [точное определение B](../preview-definition.json).

Получены **20 пар / 40 снимков**: десять сцен NQ/RDR при 1600×900 и 1920×1000. A — точный архив
`main@2672841`. B — `PR #9@0f1ae26` с четырьмя ограниченными поправками сводки в изолированном asset;
BASE/NOW/Q1 не пересчитаны другим методом. Основной режим явно «Границы хода»; отдельно показан «Путь».
Рабочий сервер/ярлык оператора не использовались и не изменялись. Весь raw OHLC/case export остался в локальном runtime.

| Сцена | Дата, срез ET, scope | Что различает |
|---|---|---|
| FOCUS | 17.12.2025 11:10, all | Сводка скрыта; свечи и созвездия занимают основное место |
| WAIT | 17.12.2025 10:35, weekday | До подтверждения: A без семьи, B с кандидатным PRE |
| CONF | 17.12.2025 10:40, weekday | Подтверждение состоялось, полного постактивационного префикса ещё нет |
| OPEN | 17.12.2025 11:10, all | Кандидат ARRIVE: открытое место и его случаи |
| FEW | Тот же день/час, weekday | Другая явная семья; мало аналогов, ARRIVE без процента |
| PULL | 10.12.2025 11:15, all | NOW R перед следующей свечой |
| REACHED | 10.12.2025 11:20, all | Все три места уже достигнуты; вместо будущей доли факт |
| BREAK | 10.12.2025 14:30, weekday | Семья слома со своим N/рамкой; малый BASE не исчез |
| ORIGINAL | Тот же день/час, original | Исходный snapshot; NOW остановлен перед сломом, ARRIVE не возобновляется |
| PATHS | 17.12.2025 11:10, all | A — частоты close; B — отдельные close-пути и диапазоны выбранных случаев |

Во всех парах машинно совпали закрытые наблюдения, состояние рынка, BASE id/состав/N/R/X/клетки/счётчики,
NOW значения/опоры/статус и геометрия основного canvas. Проверка паспортов закончилась, нарушений контракта нет,
страница не прокручивается. Это равенство на объявленных сценах, не доказательство всей истории.

**Что изменяется зрительно.** В B ответ связан с выбранным местом и его точными случаями; это полезный источник
для интеграции. Но B также вводит новые главы R/X, сворачивает семейные подробности, добавляет маркеры и меняет
основное прочтение режима «Путь». Их принятие не следует из совпадения чисел. До подтверждения остаются обычные
счётчики PRE; это конфликт правил сводки. Поэтому **B целиком не рекомендован к переносу**. Рекомендована конструкция
с сохранённым принятым экраном и отдельно проверенным связыванием вопроса/пакета/случаев.

Повторно выполнены исходные проверки веток на WAIT/OPEN/BREAK/PATHS в двух размерах: 24 запуска,
15 вернули пустой список проблем; все восемь `family_path24_check.js` прошли. Остальные результаты сохранены:
переполнение toolbar на 1600 (в A BREAK до 1730 px, обычные кадры до 1609; B PATHS до 1665),
счётчики PRE в B WAIT при 1920, и несоответствие области старого main-теста режиму PATHS.
Последний тест ожидает созвездия/полосу времени «Границ хода», когда открыт иной режим; это не доказательство
дефекта данных. Проверки не переписаны ради зелёного результата. Утверждать `problems: []` для всех сцен нельзя.

Снимки OPEN 1600 A/B, PATHS 1920 A/B, BREAK 1600 B и FOCUS 1920 B просмотрены лично.
Человеческое принятие и превосходство нового чтения **не проверены**. Сцены ошибок/UNKNOWN-подмен,
возврат live, холодный запуск и полный список защищённых различений относятся к будущей приёмке реализации,
а не выдаются за проверенные этими фотографиями.

Воспроизведение для инженера: `tools/prepare.py` → `tools/run_compare.py` → `tools/run_compare.py --checks`
→ `tools/report.py`. Это существующий Chrome/CDP collector с небольшим экспортом функций;
нового браузерного/онтологического стека нет. `prepare` проверяет зафиксированные Git-объекты и source patch,
не меняет product sources/dist. Смена исходного SHA требует нового сравнения.
