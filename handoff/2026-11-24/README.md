## Как начать работу новому агенту

1. Прочитай `AGENTS.md`, потом эту папку по порядку.
2. `git status` — убедись, что незакоммиченная работа на месте (≈77 строк статуса на 24.11). Если её нет —
   восстанови из `snapshot/working-copy-2026-11-24` (см. 06).
3. Если `git` пишет «index.lock: File exists» — в `.git/index.lock` лежит пустой файл от 11.11 (и такие же в
   `.git/worktrees/{ekran-23-5,xreach,modest-volhard-ad7f30}/`). Убедись, что git сейчас ничего не делает, и удали их.
4. Любую правку 23.5 собирай из исходников (`python design/sozvezdiya-23-5/src/build.py`), никогда не
   восстанавливай `app.js` или `d24.js` целиком из старого `.bak` — затрёшь правки других тредов.
5. Перед пушем, PR или слиянием — спроси оператора.
