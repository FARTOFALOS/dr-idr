## PR #34 — наведение не мельтешит от W1 к W2

- GitHub: https://github.com/FARTOFALOS/dr-idr/pull/34 · ветка `claude/project-thread-fqv8cn` · локально

- **Слова оператора 24.11:** «когда веду мышь от W1 к W2 по коричневым кластерам, блоки отката и продолжения по

## Как проверить ветку

```bash
git switch --detach handoff/pr32-state-colors      # или другую; рабочая копия должна быть чистой — иначе используй worktree:
git worktree add ../dr-idr-check handoff/pr32-state-colors
python design/sozvezdiya-23-5/src/build.py
start-dr-lab-23-5.cmd -NoBrowser -HistoryOnly     # из PowerShell, не через пайп
node tests/tp235_page.mjs http://127.0.0.1:8735/23-5/
```

**Не переключай ветку в рабочей копии оператора** — там незакоммиченная работа; для проверки — отдельный worktree.

## Как откатить

- PR не слит → ничего на `main` не изменилось; закрыть PR = отказаться.
- Если слит → `git revert <merge-commit>` на ветке, через PR.
- В рабочей копии → см. [02-rabochaya-kopiya.md](02-rabochaya-kopiya.md).
