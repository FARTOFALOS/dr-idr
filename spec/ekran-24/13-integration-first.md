# 13 · Первый интеграционный вариант

15.10.2026, `codex/integration-first`: вариант для проверки, существующие визуальные правила не переопределены.

| Элемент | Смысл и реализация | Граница |
|---|---|---|
| Настройки испытания | `integrationSettings/setTrial`: PRE, ARRIVE, связанные пути независимо | Включение кандидата не принимает профиль/оцениватель |
| PRE в необязательной сводке | Кандидатные bundles направлений; наведение показывает время, final R/X и DR выбранной стороны | Ненаправленная шкала от IDR low; до подтверждения нет BASE-семьи |
| «Отсюда до места» | PR6/7 engine/gate, свой набор у каждого места, проверка `arriveBundle` | Без BASE_D/default GEO, при n<20 нет доли, bounds неизвестности сохранены |
| Выбранная строка | `candidateSelection/Highlight/Emphasis`: одна цена, packet, exact case ids | Звёзды — final R, не время первого прихода |
| Нижнее окно пути | Прежние частоты закрытий + включаемые close-пути/диапазоны выбранных случаев | Пропуск разрывает линию; свои w/активация; исторический хвост — label |
| Новая M5 | Сохраняется intent нового ARRIVE-выбора, обновляется только ответ текущего context | Прежние виды hover/pin не менялись |
| Достигнуто/слом/конец | `target_facts` отдельно от прекращения нового вопроса | Нет «100 %» вместо факта, интервал свечи ≠ knowledge close |
| Проверка сцены | `integration_audit`: существующие Trace/FOM checks с ожидаемым context | Full catalog / human acceptance не заявлены |

Цвета, свечи, DR/IDR, совместные R/X, созвездия, инспектор и открытие нижних окон сохранены. Новых подписей
поверх свечей нет. Счётчики кандидатов только в инспекторе. Сводка скрывается. Главный вид «Границы хода» прежний.
