# Исполняемая преемственность закреплённой цели

15.10.2026. Первый сквозной расчётный кандидат по прямому поручению оператора в текущем чате: подтвердить связь
исходной картины, закреплённой цели, новых M5, остаточного вопроса и установленного факта. Без нового UI,
изменения main, SC-1.1, рабочего NOW, рыночной базы или публикации нового профиля.

Выбрана иллюстративная сцена NQ/RDR 17.12.2025, исходная фаза, scope=all. Это известный реальный свидетель,
выбранный для проверки переходов, а не независимое свидетельство качества прогноза или случайная оценочная выборка.
Исходная F берётся при подтверждении. Цель закрепляется в 11:10: направленная область [1,7;1,9) SD,
M5 с закрытиями 11:30, 11:35, 11:40 (физический охват свечей 11:25–11:40). Выпуски — 11:10…11:40 через 5 минут.
Ориентация и физические цены фиксируются при выборе; при новой M5 цена не отсчитывается заново от close.

Распределение обязанностей:

- `lab/continuity24.py`: цель, общий POS_GEO, отдельное условие остатка, будущие исходы, наблюдённый факт;
- `lab/continuity_audit.py`: независимый скалярный пересчёт и проверка переходов, существующая форма результата FOM;
- доказательства проверяются существующей JSON Schema Trace `ArchitectureCheckEvidence`;
- исходный полный Trace/FOM-каталог остаётся frozen reference; это ограниченная добавленная исполняемая проверка;
- `tests/continuity24.py`: смысловые контрпримеры, включая будущее, неизвестность, общий набор и A → B.

Сначала общий M_position(t) получается из G по часам/позиции. Внутри окна отсутствие сегодняшнего посещения
становится явным условием остаточного вопроса. Его risk set — названный дочерний набор, а не переименованный общий
M_position. Разные такие условия нельзя сравнивать под видом одного условного пула. До начала окна вопрос прежний;
после наблюдения части окна цель прежняя, остаточный вопрос другой. Эта дополнительная фильтрация не объявляется
проверенной калибровкой чистого POS_GEO из исследования 15.10.

Достижение снимает свежую оценку будущего события. Новый вопрос о возвращении требует нового target и наблюдённого
выхода после посещения; пребывание в области не называется возвращением. Оценка возвращения автоматически не
выдаётся: для неё необходим собственный последовательностный отбор. Механическая проверка A → B не доказывает
эмпирического превосходства такого отбора.

Дополнительная диагностика до просмотра результатов: из шести уже сохранённых массивов исследования 15.10 взять
все WINDOW_VISIT строки POS_GEO с n_total,n_known≥20; посчитать долю строк с UNKNOWN, долю неизвестных исходов,
ширину идентификационных границ по квантилям и доли ширины ≥5/10/20 п.п. Это описание существующих данных,
без нового подбора порога и без новых независимых рыночных наблюдений. Если UNKNOWN есть, первичным представлением
кандидата выбираются границы; точка среди известных остаётся диагностикой. Границы неизвестности не называются
доверительным интервалом и не измеряют ошибку переноса на сегодняшний рынок.

и хеши. Данные 2026 не открываются. Реальный UI и операторское восприятие этим запуском не проверяются.
