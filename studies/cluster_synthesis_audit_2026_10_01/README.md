# Расчёты независимого аудита DR-LAB-CLUSTER-SYNTHESIS-1.0 (01.10.2026)

**Вопрос.** Какие из утверждений синтеза и линз аудита решаются данными. Ответ:
[`meaning/lens/2026-10-01-cluster-synthesis/otvet-auditora.md`](../../meaning/lens/2026-10-01-cluster-synthesis/otvet-auditora.md).

**Что считается.** Цели — каждая сессия 2018–2025 с установленным подтверждением, семья цели — сессии её ключа строго
раньше её даты (слепок экрана 24 в этот день), события R и X, NQ / ES / YM, ADR / ODR / RDR.
- **E1** — path-null синтеза (§11–12) на устойчивых областях `main-cluster-1`: блок старшей половины заморожен,
  каждая сессия младшей половины 1000 раз пересобрана (каждая M5 после своего подтверждения отражена с вероятностью ½
  относительно предыдущего синтетического закрытия), R / X измерены тем же правилом, Holm по R и X одной цели.
- **E2** — выбранная область семьи (L1) против простых объектов на следующей сессии: блок того же размера в
  фиксированном месте (самое частое положение L1 в семьях от 60 сессий 2006–2017), первый час при любой цене, модальная
  полоса 0,5 за весь день.
- **E3** — у скольких целей семья от 60 сессий, по окну подтверждения.
- **E4** — устойчивая область первого часа к концу своего часа: невозможна ли она уже по сегодняшнему экстремуму, и
  если нет — доля семьи с тем же состоянием и сколько целей в неё затем попали.

**Файлы.**
- `audit.py` — расчёт; читает локальную базу сессий и строки проверки `main-cluster-1`;
- `audit_results.json` — только агрегаты.

```bash
python -B studies/main_cluster_2026_10_01/check.py --lo 2018-01-01 --hi 2025-12-31 --rows <rows.json> --out <tmp.json>
python -B studies/cluster_synthesis_audit_2026_10_01/audit.py --v1rows <rows.json> --out studies/cluster_synthesis_audit_2026_10_01/audit_results.json
```

Строки целей выводятся из ленты и в репозиторий не попадают (правило 1 AGENTS.md); первая команда пересоздаёт их за
несколько минут, вторая идёт около получаса (path-null).

**Главное.**
- **E2.** Автоматическая область семьи на следующей сессии попадает не лучше фиксированного шаблона того же размера: в
  семьях от 60 сессий разница −2,4…+0,5 п.п., во всех семьях шаблон лучше на 1,9–4,0 п.п. Сама область почти всегда в
  первом часе: 85–99 %.
- **E1.** Путь без направления из тех же свечей даёт 58–84 % концентрации устойчивых областей. Избыток реальных сессий
  +3…+8 п.п. есть везде, но «структурными» вышли 3–12 % областей (ADR X — 45 % при 8 семьях).
- **E3.** Семья от 60 сессий есть у 44–46 % целей: окно подтверждения 0 — почти всегда, окно 1 — у половины, окно 2 —
  у 3–8 %, дальше — никогда.
- **E4.** К концу часа области в 44–68 % дней сегодняшний путь уже сделал её невозможной (из таких дней в неё не попал
  ни один); в остальных в неё попали 30–51 % при n/N слепка 19–22 %.

**Пределы.** E1 проверяет устойчивые области `main-cluster-1` (его У5 с биномиальным критерием, а не годовым
бутстрэпом синтеза); шаблон E2 выбран на 2006–2017 и проверен на 2018–2025; цели NQ, ES и YM в один день связаны —
интервалы считаются пересэмплированием целых лет.
