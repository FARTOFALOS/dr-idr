# Q1-пилот C1: доказательства приёмки (12.10.2026)

Исполнитель: Claude (Opus 5.5), по цели оператора от 12.10 (вечер) построить первый исторический Q1-пилот по замороженной
передаче PR #5 (`3dac913`). Код — [`lab/q1/`](../../lab/q1/README.md). Здесь только агрегаты: дат и цен нет, кроме
названия одной демонстрационной сцены. Покейсные записи (выпуски, исходы, расхождения) остаются локально в
`lab/.q1-pilot/` и в Git не попадают.

**Что установлено:** реализация совпадает с исходной процедурой A/D по каждой исторической сессии каждой проверенной
строки. Выпуски физически не перезаписываются, а исход ложится отдельной записью. «Неизвестно» нигде не превращается
в «нет» и из знаменателя не выпадает. Будущее цели не влияет ни на выпуск, ни на его идентичность.

**Что не установлено:** перенос чисел на новые дни (C2), выигрыш против простой базы на новых данных и правильность
прочтения ответа оператором. Человеческая приёмка идёт отдельно, на сцене.

## 2. Неизменность выпусков и исход отдельно

`python -B tests/q1_pilot.py` (синтетика) и `python -B lab/q1/demo.py` (настоящая сцена в чистом хранилище).

| Свойство | Как проверено | Результат |
|---|---|---|
| Повторная запись того же выпуска | тот же id и тот же payload | `IDEMPOTENT`, байты файла те же |
| Другой payload под тем же issue_id | подделанный счётчик | `Collision`, файл не тронут |
| Обычная перезапись файла | `open(..., "wb")` | отказ ОС (файл только для чтения) |
| Исход | отдельный файл со ссылкой на отпечаток выпуска | байты выпуска до и после совпали (3 из 3 на сцене) |
| Исправление исхода | будущее цели исправлено | ревизия 2 заменяет 1, обе хранятся, выпуск тот же |
| Исход на другом префиксе | префикс цели исправлен | `REFUSED`, исход не присоединён |
| Два оценивателя одной цели и среза | GEO, NODEPOS_ALL, NODEPOS_WD | три разных выпуска, ни один не перезаписан |
| Повтор на исходных входах | пересчёт и сравнение байтов | `IDENTICAL` (3 из 3 на сцене) |
| Изменились данные аналога / модель | синтетика | `INPUTS_CHANGED` / `MODEL_CHANGED`; новый расчёт — другая запись |
| Выпуск, сделанный, когда исход цели уже был в журнале | синтетика | payload тот же; в meta отмечено, что исход был |
| Правка выпуска руками | `verify()` | ловится дважды: собственный отпечаток и ссылки исходов |

## 3. «Неизвестно» как граница знания

| Пример договора | Результат |
|---|---|
| 20 = 8 YES + 10 NO + 2 UNKNOWN | n_known 18, точка 8/18, границы [8/20, 10/20]; неизвестные остаются в n |
| Достижение видно, другая свеча отсутствует | YES |
| Достижение после дыры | YES, время первой свечи неизвестно |
| Достижения не видно и есть дыра | UNKNOWN, не NO |
| Свеча целиком за местом (гэп) | достижение (порог, не исполнение) |
| Слом DR после среза | горизонт метки не сокращается |
| n < 20 | число не публикуется, счётчики сохраняются |
| n ≥ 20, все исходы неизвестны | точки нет, «исход неизвестен у всех» |
| Будущее цели переписано (синтетика и настоящая база) | выпуск тот же до байта вместе с id; исход цели меняется (на сцене «не дошли» → «дошли») |
| Будущее участника переписано (синтетика и настоящая база) | состав тот же; метка участника и счёт меняются; отпечаток входов другой, значит это другой выпуск |

| Набор | В наборе → пригодны → не были у места → там же | дошли · не дошли · неизвестно | Ответ |
|---|---|---|---|
| Семья дня недели | 156 → 155 → 131 → 9 | 6 · 3 · 0 | мало сессий (числа нет) |
| Ключ без дня недели | 709 → 707 → 614 → 37 | 14 · 21 · 2 | 37,8–43,2 % (среди известных 40 %) |
| Все подтверждённые (GEO) | 4 722 → 2 492 → 2 315 → 97 | 32 · 60 · 5 | 33,0–38,1 % |

Исход цели — «до 16:00 не дошли». По 63 открытым срезам этой цели и места охват восстанавливается из сохранённых
попыток. GEO дал число 63 раза из 63, ключ без дня недели — 17, семья дня недели — 0 (во всех 63 «мало сессий»). Это
наблюдение одной сцены к решению D1, а не измерение.

Проверка страницы [`tests/q1_page_check.js`](../../tests/q1_page_check.js) в браузере на двух сценах (NQ RDR и ES ODR):
показанные числа, цепочка отбора, строки сессий и список сохранённых ответов совпадают с ответом сервера; будущих
свечей на странице нет; ответ помечен как пилот вне шлюза SC-1.1. Проблем 0.
