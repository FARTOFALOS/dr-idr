# Замеры к аудиту созвездий экрана 24 (18.10.2026)

Смысл и выводы — [`meaning/lens/2026-10-18-audit-sozvezdij/`](../../meaning/lens/2026-10-18-audit-sozvezdij/README.md).
Всё считается рабочими функциями экрана (`lab/scene24.py`, `lab/zonemap24.py`), в репозитории только агрегаты.
История 2006–2025 уже видена линией, поэтому это разведка, а не приёмка. 2026 не открывался.

| Скрипт | Что меряет | Результат |
|---|---|---|
| `anatomy.py` | Состав созвездий во всех семьях по дню недели с N ≥ 20 на конец базы. Сколько зон и какая доля семьи в них; где по времени лежит масса зон (ранние / середина / поздние); порядок окончательных R и X внутри зон; глубина; доля слома DR против семьи; когда случаются окончательные точки | `anatomy.json` |
| `share_vs_status.py` | Без заглядывания вперёд, цели 2018–2025, семья только из более ранних дат. Доля на подписи зоны против того, легла ли туда окончательная точка цели, по статусу через 30 / 60 / 120 минут; перенос всей карты по дню недели и по всем дням, отдельно для семей N ≥ 60 и N 20–59 | `share_vs_status.json` |
| `author_key.py` | Опубликованный ключ автора NQ · пятница · RDR · шорт · 10:30–11:00: его процедура на нашей ленте (DR true, максимальный откат в окне входа 10:45–12:00, как в линзе 6) против созвездий экрана 24 на тот же ключ | `author_key.txt` |

```bash
python -B studies/audit_sozvezdij_2026_10_18/anatomy.py --out studies/audit_sozvezdij_2026_10_18/anatomy.json            # ~1 мин
python -B studies/audit_sozvezdij_2026_10_18/share_vs_status.py --out studies/audit_sozvezdij_2026_10_18/share_vs_status.json  # ~10 мин
python -B studies/audit_sozvezdij_2026_10_18/author_key.py > studies/audit_sozvezdij_2026_10_18/author_key.txt            # ~10 с
```

Нужна локальная база сессий `lab/.runtime/boxes_*` (`lab/build_boxes.py`).

**Правила классов в `anatomy.py` и `share_vs_status.py`** объявлены здесь, а не в контракте:
- зона ранняя, если начинается в окне активации или в следующие 15 минут;
- поздняя, если доходит до последних 15 минут блока;
- остальные — середина.

Логика целей, семей и статуса в `share_vs_status.py` повторяет
[`studies/zone_map_3_2026_10_01/check.py`](../zone_map_3_2026_10_01/README.md). Перенос для семей N ≥ 60 совпал с его
результатами; новое — доля на подписи по статусам и малые семьи.
