# Проверка representation `zone-map-3` на 2018–2025 (01.10.2026)

**Вопрос.** Что даёт карта зон `zone-map-3` ([`lab/zonemap24.py`](../../lab/zonemap24.py)) на истории:
- переносится ли масса зон на следующие сессии;
- добавляет ли совместная структура «цена × время» что-то сверх гистограмм;
- что делает статус по сегодняшнему экстремуму;
- чем карта отличается от путей без направления.

Ответ и пороги приёмки на новых сессиях — [`meaning/12-karta-zon.md`](../../meaning/12-karta-zon.md).

**Пределы.** Это разведка: 2018–2025 эта линия уже видела. Приёмка (meaning/12 §6) идёт только на сессиях после 2025
года.

**Что считается.** Цели — сессии 2018–2025 с установленным подтверждением; семья цели — ключ строго до её даты, по дню
недели и отдельно без него. Для каждой цели и события:
- зоны семьи и куда легло её собственное окончательное событие;
- ранние и поздние зоны;
- плотность зон против фона семьи;
- статус каждой зоны через 30 / 60 / 120 минут после подтверждения цели.

Сравнения:
- шаблон — ранний блок 0,5 × 60 из 2006–2017, [`studies/cluster_synthesis_audit_2026_10_01`](../cluster_synthesis_audit_2026_10_01/README.md);
- первый час при любой цене;
- модальная полоса за день;
- та же площадь, что у зон, выбранная только по произведению ценовой и временной гистограмм.

Null-диагностика — та же карта на путях без направления, 20 повторов, семьи от 60 сессий на конец базы.

```bash
python -B studies/zone_map_3_2026_10_01/check.py --out studies/zone_map_3_2026_10_01/check_results.json   # ~13 минут
```

`check_results.json` — только агрегаты.

**Главное** (по дню недели, семьи от 60 сессий):
- **Перенос всей карты** — 0,67–0,82, у V2 было 0,44–0,61. Без дня недели — 0,86–1,02.
- **Плотность.** Зоны в 9–12 раз плотнее фона.
- **Поздние зоны** по дню недели переносятся хуже: 0,41–0,76.
- **Против гистограмм на той же площади.** У отката R зоны добавляют +2,7…+3,8 п.п.; у расширения X разницы нет.
- **Ранняя зона** почти не отличается от шаблона.
- **Статус.**
  - «невозможна» не сбылась ни разу;
  - «держится» сбылась в 27–67 % случаев;
  - «возможна» — в 3–7 %.
- **Null.** На путях без направления алгоритм строит столько же зон той же массы.
