# Проверка representation DR-LAB-ZONE-MAP-2.0 для её аудита (01.10.2026)

**Вопрос.** Что даёт `zone-map-2` на истории: сколько зон, переносится ли их масса на следующие сессии, отличаются ли
они от путей без направления, что делает статус по сегодняшнему экстремуму. Ответ:
[`meaning/lens/2026-10-01-zone-map-2/otvet-auditora.md`](../../meaning/lens/2026-10-01-zone-map-2/otvet-auditora.md).

**Файлы.**
- `zonemap.py` — `zone-map-2`, написанная заново по тексту спецификации. Выбор там, где текст допускает два прочтения,
  назван в начале файла (A1–A4). Это не продукт: экран 24 её не использует.
- `audit.py` — проверка §43. Цели — сессии 2018–2025, семья — ключ строго до даты цели, по дню недели (§2.1) и явно
  без него (§2.2). Считается масса зон, попадание следующей сессии, ранние и поздние зоны, статус §24 через 30 / 60 /
  120 минут после подтверждения, та же карта на путях без направления (20 повторов, §33.2).
- `holes.py` — куда попадает следующая сессия: в маску зоны, в пустую клетку её конверта или мимо.
- `audit_results.json`, `holes_results.json` — только агрегаты.

```bash
python -B studies/zone_map_2_audit_2026_10_01/audit.py --out studies/zone_map_2_audit_2026_10_01/audit_results.json   # ~12 минут
python -B studies/zone_map_2_audit_2026_10_01/holes.py --out studies/zone_map_2_audit_2026_10_01/holes_results.json   # ~5 минут
```

**Главное** (семьи от 60 сессий):
- **Перенос.** Карта по дню недели переносит вперёд 0,44–0,61 своей массы, без дня недели — 0,68–0,85. Поздние зоны —
  0,11–0,48 и 0,43–0,57.
- **Дыры.** Конверт зоны на 44–52 % состоит из клеток без исторических событий. Следующие сессии попадают в эти дыры
  в 0,38–0,73 раза так же часто, как в маску, и по правилу §8 считаются остатком.
- **Null.** На путях без направления алгоритм строит столько же зон той же массы, с тем же числом поздних зон.
- **Статус.**
  - «Невозможна» не сбылась ни разу.
  - «Держится» сбылась в 25–67 % случаев.
  - «Возможна» — в 1–5 % случаев.

**Пределы.**
- 2018–2025 эта линия уже видела, поэтому это разведка, а не решающая проверка.
- Устойчивость к сетке и пересэмплирование (§43.5–6) не считались.
- Цели NQ, ES и YM в один день связаны.
